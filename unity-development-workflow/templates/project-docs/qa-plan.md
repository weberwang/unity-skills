# 测试与性能计划

## 缺陷分级

- P0：无法启动、数据丢失、安全/合规阻断或核心流程不可完成。
- P1：关键体验或任一批准平台交付不可接受。
- P2：可绕过的功能或体验问题。
- P3：非阻断优化项。
